# User-controlled content retention with bounded purge

User Agent, reading and response content is retained until the User deletes it; deletion hides it from product queries immediately and hard-purges it within 30 days. Full chat is not placed in a general search index, Admin sees redacted metadata by default, and plaintext support access requires a time-limited User grant. This replaces indefinite identifiable retention with an implementable privacy and support boundary.
