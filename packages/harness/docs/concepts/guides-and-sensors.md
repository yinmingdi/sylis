# Guides and Sensors

## Guides

Guides reduce the chance of bad action before the agent acts.

Examples:

- `AGENTS.md`
- `ARCHITECTURE.md`
- product specs
- design rules
- architecture boundaries
- quality gates
- references

## Sensors

Sensors detect whether action worked after the agent acts.

Examples:

- typecheck
- lint
- tests
- build
- browser console
- screenshots
- visual diff
- logs
