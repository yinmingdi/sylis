## 2. 最终文档完成门禁

文档包只有同时满足以下条件才可冻结：

1. 上表每一项都有唯一权威章节，不依赖旧 `/guide/lexicon-architecture` 的隐藏定义。
2. `standard-json` 中每个正式数组都能映射数据库表；每个目标数据库表也被标记为 artifact、runtime 或 operational 所有。
3. 当前 API module、路由族、Web 页面/组件组、Prisma 文件、package、service 和 workflow 均有明确去向。
4. 所有外部结论链接到规范、官方文档或原始研究；产品取舍明确标记为 Sylis 决策。
5. VitePress build、内部链接、Mermaid、`git diff --check` 和密钥扫描通过。
