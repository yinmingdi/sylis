# 数据库强约束覆盖矩阵

本文逐条跟踪 [`relational-schema.md` 第 17 节](./relational-schema.md#17-强制数据库约束) 的 50 条强约束，是 `B-04` 的细粒度实现账本。状态只描述当前源码覆盖，不代替最终销毁并重建空库、加载唯一 `0.0.1` baseline、负向约束测试、权限测试和 E2E 证据。`0.0.1` 不实现旧库升级、数据迁移、兼容层、回填或双写。

## 状态定义

| 状态          | 含义                                                       |
| ------------- | ---------------------------------------------------------- |
| `IMPLEMENTED` | 所需 schema/SQL/service 边界源码已落地，仍须在 `I-03` 验证 |
| `PARTIAL`     | 只有部分约束或只有 service 校验，尚不能证明规则完整成立    |
| `MISSING`     | 当前没有足够的 schema/SQL 强制实现                         |
