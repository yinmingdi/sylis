# Retrieval Protocol

Before creating new code, search for existing capability.

Retrieve:

- Similar components, functions, hooks, classes, services, commands, routes, or pages.
- Existing tests and stories.
- Callers and callees.
- Relevant design-system or architecture rules.

After retrieval, state the reuse decision:

- Reuse existing.
- Extend existing.
- Create new.
- Do not reuse, with reason.

Reasons not to reuse:

- Wrong layer.
- Wrong domain.
- Wrong dependency direction.
- Behavior mismatch.
- Visual-only similarity.
- Missing required behavior.
