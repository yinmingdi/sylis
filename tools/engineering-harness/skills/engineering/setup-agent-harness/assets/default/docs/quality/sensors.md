# Sensors

Sensors are feedback mechanisms used after action.

## Computational Sensors

- Typecheck.
- Lint.
- Unit tests.
- Build.
- Import-boundary checks.

## Runtime Sensors

- Browser console.
- Network panel.
- Logs.
- Traces.

## Visual Sensors

- Screenshots.
- Visual diff.
- Responsive checks.
- Text overflow checks.

## Inferential Sensors

- AI review.
- Semantic review.
- Human review.
