# Objective-level FSRS before IRT/CAT

Memory state belongs to a minimal LearningObjective and is scheduled with a maintained FSRS implementation; Exercise is replaceable evidence and Assessment does not update memory. Version 0.0.1 uses deterministic heuristic selection and collects classical item statistics, because the project has no calibrated response population that could justify IRT, CAT, CEFR or vocabulary-size claims.
