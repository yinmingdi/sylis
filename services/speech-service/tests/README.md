# 测试脚本

这个目录包含所有测试相关的脚本和音频文件。

## 📁 文件说明

### 测试脚本

- **`test_pytorch_model.py`** - PyTorch 模型评分测试
  - 测试训练好的音素识别模型
  - 显示详细的评分分析

### 测试音频

- **`hello.wav`** - "hello" 发音测试音频
- **`bye.wav`** - "bye" 发音测试音频

### 单元测试

- **`conftest.py`** - pytest 配置
- **`unit/`** - 单元测试
- **`integration/`** - 集成测试
  - `test_api.py` - API 集成测试

---

## 🚀 使用方法

### 测试 PyTorch 模型

```bash
# 从 speech-service/ 根目录运行
python tests/test_pytorch_model.py tests/hello.wav 'hello'
python tests/test_pytorch_model.py tests/bye.wav 'bye'

# 或者从 tests/ 目录运行
cd tests
python test_pytorch_model.py hello.wav 'hello'
```

## 📊 评分解读

### 分数范围

- **80-100分**: ✅ 优秀 - 发音标准
- **60-79分**: 🆗 良好 - 略有瑕疵
- **40-59分**: ⚠️ 需要改进 - 有明显问题
- **0-39分**: ❌ 需要大量练习 - 发音错误

### 难音素标记

带 ⚠️ 标记的音素是公认的难音素：

- L, R - 流音
- OW, AW - 双元音
- TH, DH - 齿摩擦音
- V, W - 唇音

### GOP 分数解读

```
GOP (Goodness of Pronunciation):
  > 1.0   优秀
  0 ~ 1.0 良好
  -1 ~ 0  需要改进
  < -1.0  较差
```

## 🎯 添加自己的测试音频

1. 准备音频文件（16kHz, WAV 格式）
2. 放到 `tests/` 目录
3. 运行测试：

```bash
python tests/test_pytorch_model.py tests/your_audio.wav 'your text'
```

**音频要求：**

- 格式：WAV
- 采样率：16kHz（推荐）
- 时长：<10秒
- 内容：清晰的英文单词/句子
