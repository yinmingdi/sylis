# Harness Engineering

Harness Engineering treats the agent environment as a control system around the model.

The toolkit focuses on:

- Guides: pre-action project memory.
- Sensors: post-action feedback.
- Tool capabilities: MCPs, shell, browser, search, issue trackers.
- Generated facts: setup-detected project state.
- Harnessability: how controllable the project is by an agent.
- Governance: how failures become better guides or sensors.
