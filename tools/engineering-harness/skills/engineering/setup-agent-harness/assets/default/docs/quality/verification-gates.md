# Verification Gates

Define completion evidence by task type.

## Feature Work

- Relevant implementation completed.
- Similar code checked before new code.
- Focused tests or equivalent validation passed.

## Bug Fix

- Reproduction path identified.
- Regression evidence collected.
- Relevant tests or manual proof recorded.

## UI Work

- Page or component renders.
- Console is checked.
- Screenshot or visual evidence is collected when relevant.
- Responsive and text overflow states are checked when relevant.

## Figma-to-Code Work

- Specific Figma node or scoped frame was used when possible.
- Design context was inspected.
- Variables/styles were checked when token fidelity matters.
- Similar code/components were retrieved before implementation.
- Figma output was translated into project conventions.
- Rendered UI evidence was collected.
- Screenshot or visual comparison was collected when fidelity matters.
- Console errors were checked.
- Text overflow, responsive layout, icons, and image/SVG placement were checked when relevant.

## Refactor

- Behavior is preserved.
- Affected tests/checks pass.
- Architecture boundaries remain valid.
