# Design System

Record:

- Tokens.
- Typography.
- Spacing.
- Color.
- Icon rules.
- Components and primitives.
- Rules for mapping design primitives to code.

## Figma Mapping

Record how design-system concepts map between Figma and code:

- Figma variables/styles -> project tokens.
- Figma components/variants -> code components.
- Figma icons -> icon library or asset handling.
- Figma layout primitives -> project layout components or CSS conventions.
- Code Connect availability.
- Storybook or component documentation links.

When Figma and code disagree, this file should define which source wins and how the agent should resolve the mismatch.
