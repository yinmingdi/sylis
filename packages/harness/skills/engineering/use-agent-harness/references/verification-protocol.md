# Verification Protocol

Use project-local gates first:

- `docs/quality/verification-gates.md`
- `docs/quality/sensors.md`
- `docs/generated/command-registry.md`

## Evidence Types

- Typecheck result.
- Lint result.
- Focused test result.
- Build result.
- Browser render.
- Screenshot.
- Console/network inspection.
- Visual diff.
- Accessibility check.

Do not claim completion without evidence appropriate to the task.

## Figma-to-Code Evidence

For Figma-driven UI work, collect evidence for:

- Figma node or scoped frame used.
- Design context inspected.
- Variables/styles inspected when relevant.
- Similar code retrieved.
- Rendered UI screenshot or visual baseline comparison.
- Browser console check.
- Responsive layout check when relevant.
- Text overflow check when relevant.
- Icon, SVG, and image placement check when relevant.

If a large Figma frame was used, record why a smaller node could not be used.
